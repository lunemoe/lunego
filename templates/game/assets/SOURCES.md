# p9 正式素材接入

来源：既有 `p9-dungeon-arpg` v2.2.1 CC0 素材包，完整原始素材现已收拢到本仓库的 [`art/p9/`](../../../art/p9/)。这里纳入当前游戏实际使用的 35 项生产资源；原始生成脚本、原始大图和历史替代版本不进入运行时目录。运行与构建只使用本仓库。

- PNG/OGG 直接复制，未重新绘制或改动图像、声音数据。逐项原始来源保留在 manifest 的 source；完整许可与署名说明保留在 LICENSE.md / ATTRIBUTION.md。
- 以已规范化 manifest 的动画索引为主；旧条目中的 row + 列区间展开为显式帧索引。玩家四向行由框架 `animationFrames(..., {row})` 选择。
- `nine-slice` / `ui-part` 归一为框架 image 类型，`tileset-atlas` 归一为 tileset；不适用的 null 九宫格信息移除。血条/经验条的切片边界修正为 2，避免错误的整图切片造成破碎显示；像素内容不变。
- 血条/经验条填充图中的有效区域为 `(3,3,10,10)`；通过 manifest 的显式 frame 裁切透明留白，DOM 背景与纹理使用同一裁切元数据，满血显示到条末端。
- 资源元数据经 `lunego gen` 生成 `Assets/AssetPack`。游戏角色、两套地面、物品图标、技能图标、UI 皮肤与音频直接消费同一生成物，版本与内容进入存档指纹。
