P1 gameplay-domain semantics for kits: quest escort objectives with a pure
position/alive progress entry and explicit death failure, weekly repeat mode
with injected tick/week length, persisted day/week state; dialogue hub
back-edges with reachability validation and a configurable deterministic step
limit; encounter snapshots carry spawn RNG state when the stream exposes it;
perception accepts an injected line-of-sight callback.
