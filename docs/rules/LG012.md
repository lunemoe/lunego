# LG012 禁止杂物目录、模块级可变状态、超长文件

## 规则

- 不创建 `utils/`、`common/`、`helpers/` 这类杂物目录，也不从这类目录 import。
- 模块顶层不得有 `let` / `var` 或可变集合（`Map` / `Set` / `WeakMap` / `WeakSet`）。
- 单个文件不超过 400 行。

## 原因

杂物目录会吸走所有无家可归的代码；模块级可变状态破坏确定性；超长文件让职责和审查都失控。

## 强制手段

`@lunego/eslint-plugin` 的 `lg012`（默认 `maxLines: 400`），并在根 ESLint 配置中对所有 TS 启用。

## 修法

按职责命名模块（`entity-store.ts`、`world-hash.ts`）；状态放进 World；超长文件按生命周期、查询、快照、tick 管线拆分。
