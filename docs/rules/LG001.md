# LG001 逻辑层不依赖 DOM 和浏览器 API

## 规则

逻辑代码（`packages/core`、`kits/*/logic`、`features/*/logic`）不得引用 `document`、`window`、`HTMLElement`、Canvas 等浏览器类型或全局。

## 原因

逻辑必须能在主线程、Worker、Node 测试中运行；DOM 依赖会让回放与联机失效。

## 强制手段

- 逻辑侧 tsconfig 的 `lib` 只有 ES2024，`types: []`，不含 DOM。
- dependency-cruiser 禁止 logic → view / host / 浏览器包。
- ESLint LG002 补充检查浏览器全局。

## 修法

把平台能力放到表现层或 host；逻辑只消费 Command、Cue 和确定性 Service。
