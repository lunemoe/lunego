# LG003 System / Handler 必须声明读写与收发

## 规则

`reads`、`writes`、`emits`、`listens`、`cues` 必须覆盖实际访问。查询、事件、Cue、模型和组件都受此约束。

## 原因

声明就是文档；调度器据此排序、检查冲突，运行时守卫据此阻止隐式耦合。

## 强制手段

- 注册期：未注册的 state / event / cue 直接报错；调度器检查事件先后与环。
- 开发期：`ctx.read` / `ctx.write` / `ctx.mutModel` / `ctx.emit` / `ctx.events` / `ctx.cue` 未声明即抛 `LG003`。
- 调度冲突以 `schedule-conflict` 诊断报告。

## 修法

在 `defineSystem` / `defineHandler` 中补声明；确实需要跨 tick 读事件时写 `{ event, prev: true }`。
