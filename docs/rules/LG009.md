# LG009 不用魔法字符串引用内容或资源

## 规则

内容 ID、资源 ID 通过类型化值引用；禁止散落的裸字符串。

## 原因

字符串拼写错误在运行时才暴露；类型化 ID 让重构与引用检查可靠。

## 强制手段

- `t.ref(ContentType)` 产出 branded `ContentId`；`parseContentId` 是边界入口。
- `t.asset(kind)` 记录资源类别。
- `lunego gen` 生成 `features/_generated/ids.ts`，包含 `CueIds`、`ContentTypeIds`、`ContentIds`；内容/资源仍不得使用散落字符串。

## 修法

在内容定义处生成/导出常量，组件和系统只引用常量。
