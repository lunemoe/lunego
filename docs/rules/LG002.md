# LG002 逻辑层不使用非确定性 API

## 规则

逻辑不得使用 `Math.random`、`Date`、`performance.now`、`setTimeout` / `setInterval`、`async` / `await`、`Intl`、区域设置 API、DOM、平台随机源；`sin` / `cos` / `atan2` / `exp` / `pow` / `sqrt` 等必须走 `@lunego/core/math`。

## 原因

相同初始状态 + 相同命令序列必须得到相同结果，才能回放、逐 tick 校验和未来联机。

## 强制手段

- `@lunego/eslint-plugin` 的 `lg002`，默认对逻辑目录启用。
- Testkit 的确定性双跑（`assertDeterministic`）与 core 的哈希/读档透明测试。
- 命令结果 Promise 仅作为外部确认句柄；`packages/core/src/world.ts` 显式开启 `allowPromise`，不放开 async/await。

## 修法

随机用 `ctx.rng('name')`；时间用 `ctx.time` 或 tick；数学用 `@lunego/core/math`；异步结果以 Command 形式进入 World。
