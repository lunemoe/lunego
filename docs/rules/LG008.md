# LG008 框架不 import 游戏代码，框架里不出现玩法名词

## 规则

`packages/*`、`kits/*` 不 import `features/*`、`games/*`、`content/*`；框架标识符不使用具体玩法概念。

## 原因

框架必须能被任意游戏复用；玩法渗入框架后，第二个游戏就会被迫继承第一个游戏的假设。

## 强制手段

- dependency-cruiser `packages-no-game-code`。
- “玩法名词”无法完全机器判断，**需人工审查**（命名、注释、测试数据）。
- 测试夹具可以使用玩法词，但不得被核心源码 import。

## 修法

把玩法逻辑留在 feature；只有被第二个场景需要且与玩法无关时才晋升为 kit。
