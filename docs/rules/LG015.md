# LG015 新 feature 必须有 README 契约和测试；修改框架必须附变更记录

## 规则

每个 `features/<name>` 必须有 README（意图、公共接口、不变量、依赖）和测试；框架改动必须附带 changeset 与规则/文档更新。

## 原因

feature 的契约和测试就是 AI 的上下文边界；没有契约的模块会被误用。

## 强制手段

- CI 运行 build / lint / depcruise / test。
- changesets 管理框架变更记录。
- `lunego check` 与 `docs/generated/` 项目地图在后续 CLI 批次补齐；**特征 README 自动段落尚未机器强制**，当前由审查兜底。

## 修法

新建 feature 时同时写 README 与场景测试；修改框架时运行 `pnpm changeset`。
