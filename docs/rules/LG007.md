# LG007 逻辑与表现互不 import 实现

## 规则

`features/*/logic` 不得 import `features/*/view` 或表现层包；`view` 不得 import 任何 feature 的 `logic` 实现。

## 原因

逻辑是纯状态机；表现只读镜像。互相 import 会让平台依赖和渲染时序渗入逻辑。

## 强制手段

- dependency-cruiser `logic-no-view-imports`、`view-no-logic-implementation`。
- 逻辑 tsconfig 不含 DOM。
- 类型层只有 `schema.ts`、core 与表现包类型可共享。

## 修法

逻辑产出 Event / Cue；表现层订阅镜像并调用 Query。
