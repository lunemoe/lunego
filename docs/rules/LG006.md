# LG006 feature 只能 import 其他 feature 的 schema.ts

## 规则

跨 feature 只能导入对方的 `schema.ts`；不得导入内部 systems、handlers、queries、rules、view。

项目根 `features/_generated/` 下的资源/ID 元数据不属于某个 feature，可只读导入。此例外仅覆盖公共生成元数据，不允许导入其他 feature 自己的 `_generated/registry.ts`；LG014 仍禁止手改生成物。

## 原因

`schema.ts` 是公共契约；内部文件是私有实现。允许跨内部导入会让 feature 退化成一个大泥球。

## 强制手段

- dependency-cruiser `feature-schema-only`（运行时依赖）。
- `deps` 必须无环，由注册期校验。

## 修法

需要能力时调用对方 Query、发送对方监听的事件，或把能力晋升为 kit。
