# LG005 写权限归属（writers）

## 规则

组件、Tag、Model 默认只有定义它的 feature 能写。其他 feature 需要写入时，在定义处声明 `writers: [...]`。

## 原因

任何一个字段的写入者都可以被列举；跨 feature 直接改状态是腐坏的起点。

## 强制手段

- 注册期：`WorldCatalog` 校验每个 System / Handler 的 `writes` 是否在 owner + writers 内，否则抛 `LG005`。
- `writers` 中的 feature 名必须存在。

## 修法

优先让 owner feature 提供 Command 或请求事件；确实需要多方写入时显式加 `writers`。
