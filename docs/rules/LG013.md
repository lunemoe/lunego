# LG013 不写临时实现

## 规则

禁止 `any`、`@ts-ignore` / `@ts-expect-error` / `@ts-nocheck`、`as unknown as` 蒙混，以及 `TODO` / `FIXME` / “先这样” / “占位” 等标记。

运行时代码禁止空函数体与抛出未实现提示的入口；公开函数或 `run` 入口不能忽略全部输入而只返回常量成功/数据。无状态工厂和有意的生命周期回调不据此判定为空实现。测试夹具的空函数体可保留，测试本身不得为空。

## 原因

临时接口会被 AI 当成稳定契约继续叠加；占位注释则是永不兑现的债务。

## 强制手段

- `@lunego/eslint-plugin` 的 `lg013`。
- TypeScript 最严格配置。
- 审查兜底：空实现、假 fallback、未接线路径都视为违规。

## 修法

需要表达未知输入时用 `unknown` + 校验/类型守卫；缺能力就实现，或明确报告缺少前置条件。
