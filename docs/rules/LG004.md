# LG004 状态只能在 System / Handler 中修改

## 规则

外部只能发 Command；组件、Tag、Model 的写入只发生在 tick 内的 System / Handler。tick 之外使用捕获的 context、草稿或只读视图写入必须报错。

## 原因

唯一写入路径保证数据流可追踪、可回放，也避免表现层与逻辑层互相污染。

## 强制手段

- 开发期 context 活跃性检查：过期 context 的任何状态操作抛 `LG004`。
- Model 草稿/只读代理拦截 tick 外写入；组件视图区分读写。
- `world.spawn/add/remove/despawn` 仅作为测试/装载入口，tick 内调用会抛错。

## 修法

改为发送 Command，由 Handler 修改；测试装载用 testkit 的 `spawn`。
